# Two Explainers, One Recording

An interactive reader's guide to the paper *Reliable Explainability Across Four
Arabic Speech Emotion Corpora: A Null-Controlled Cross-Representation Comparison*.

- `index.html` — English
- `id.html` — Bahasa Indonesia

Both are self-contained static pages. The interactive sections recompute the
paper's figures in the browser from its own 996 label pairs, so nothing is
quoted: the permutation test, the attainable ceiling (43.67%) and the chance
level (19.87%) are all calculated live.

No build step. Open either file directly, or serve the folder with any static host.
